# astanamg-site

Сайт производителя мебели на заказ **Astana Mebel Group** (Астана, собственное производство с 2011 года).
Заменяет текущий astanamg.kz на WordPress + Elementor. Сейчас готова главная страница (MVP).

## Стек

- Next.js 15 (App Router), статический экспорт (`output: 'export'`)
- TypeScript
- Tailwind CSS v4 — токены в `@theme` внутри `app/globals.css`, без `tailwind.config`
- Шрифт Onest через `next/font/google` (latin + cyrillic)
- Изображения через `next/image`, `unoptimized: true` — webp готовятся заранее скриптом

## Команды

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # статическая сборка в /out — её и выкладываем на хостинг
npm run typecheck
npm run images     # пересобрать webp и og-image из фото клиента
```

> **Пересобирать сайт минимум раз в год.** Стаж компании считается функцией
> `yearsInBusiness()` от 2011 года, но при статическом экспорте значение
> фиксируется в HTML на момент сборки. Без пересборки в январе на сайте
> останется прошлогодняя цифра (и год в футере).

## Структура

```
app/                  layout, страница, globals.css (токены)
components/
  ui/                 Container, Button, SectionHeading, Media, Accordion, Icons, Wordmark
  layout/             Header, MobileMenu, Footer, MobileBar
  sections/           8 секций главной + Rail (лента проектов) и ContactForm
content/              все тексты сайта — в компонентах текста нет
lib/                  company.ts (контакты, срок, стаж), format.ts, jsonld.ts, cn.ts
scripts/images.mjs    конвейер фото: оригиналы → webp, сборка og-image
public/images/        только webp
```

## Правила контента

- **Срок изготовления** на всём сайте один — `LEAD_TIME` в `lib/company.ts`:
  «от 21 до 35 рабочих дней». Других формулировок быть не должно.
- **Цены** — только в `content/pricing.ts`. FAQ, кейсы и JSON-LD берут цифры оттуда.
- **Почта** на сайте не выводится. Телефон и WhatsApp — из `lib/company.ts`.
- **Логотип**: растровый PNG клиента (градиент, тень, белая обводка) — только на светлом фоне в шапке.
  На `forest` (футер, «Производство») — текстовый локап `Wordmark`. Инверсной версии у клиента нет.
- Карточки каталога ведут на `/?type=<id>#contacts` — в форме заранее выбирается тип мебели.
- **Заявка уходит в WhatsApp**: форма собирает текст и открывает `wa.me` с предзаполненным
  сообщением. Сервера нет, заявки нигде не хранятся — переписка остаётся в WhatsApp клиента.
- Кейсы показывают только заполненные параметры: пустых прочерков в карточке быть не должно.

## Фото

Оригиналы берутся с `astanamg.kz/wp-content/uploads/2025/07/`, кэшируются в `.image-cache/`
(в git не попадает) и режутся в три ширины — **480 / 960 / 1440** — в webp, без увеличения.
Ширины совпадают с `deviceSizes` в `next.config.ts`; `lib/imageLoader.ts` подставляет нужную
нарезку (`kitchens.webp` → `kitchens-960.webp`), поэтому `next/image` отдаёт честный `srcSet`
даже при статическом экспорте. У слота есть потолок `max`: миниатюры каталога дальше 480 px
не растут, карточки проектов — дальше 800 px. Логотип идёт с `unoptimized` — он один на все экраны. Соответствие
файлов клиента и слотов на сайте — в `scripts/images.mjs`. `og-image.jpg` собирается из того же
кадра, что hero, — JPEG, потому что мессенджеры читают webp в превью ненадёжно.

## Типографика

Onest. Шкала жёсткая, имя утилиты = размер в px: `text-32 md:text-48 lg:text-72`.

| Утилита | Размер | Интерлиньяж | Трекинг |
|---|---|---|---|
| `text-14` | 14px | 1.5 | — |
| `text-16` | 16px | 1.6 | — |
| `text-18` | 18px | 1.6 | — |
| `text-24` | 24px | 1.3 | −0.01em |
| `text-32` | 32px | 1.18 | −0.02em |
| `text-48` | 48px | 1.06 | −0.025em |
| `text-72` | 72px | 1.0 | −0.03em |

Заголовки — вес 600. Скругления — не больше 4px (вся шкала `rounded-*` сведена к 4px).
Теней нет (шкала `shadow-*` = `none`), глубина — контрастом фонов.

Сетка: максимум 1280px, поля 24px на мобильном / 64px на десктопе.
