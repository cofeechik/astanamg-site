# astanamg-site

Сайт производителя мебели на заказ **Astana Mebel Group** (Астана, собственное производство с 2011 года).
Заменяет текущий astanamg.kz на WordPress + Elementor.

## Стек

- Next.js 15 (App Router), статический экспорт (`output: 'export'`)
- TypeScript
- Tailwind CSS v4 — токены в `@theme` внутри `app/globals.css`, без `tailwind.config`
- Шрифт Onest через `next/font/google` (latin + cyrillic)
- Изображения через `next/image`, `unoptimized: true` — webp готовятся заранее

## Команды

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # статическая сборка в /out
npm run typecheck
```

> **Пересобирать сайт минимум раз в год.** Стаж компании считается функцией
> `yearsInBusiness()` от 2011 года, но при статическом экспорте значение
> фиксируется в HTML на момент сборки. Без пересборки в январе на сайте
> останется прошлогодняя цифра (и год в футере).

## Структура

```
app/            layout, страница, globals.css (токены)
components/
  ui/           Container, Button, SectionHeading, Media, Accordion
  layout/       Header, Footer, MobileBar
  sections/     секции главной
content/        все тексты сайта — в компонентах текста нет
lib/            company.ts (контакты, срок, стаж), jsonld.ts
public/images/  только webp
```

Срок изготовления на всём сайте один — `LEAD_TIME` в `lib/company.ts`:
**от 21 до 35 рабочих дней**. Других формулировок быть не должно.

## Типографика

Onest. Шкала жёсткая, имя утилиты = размер в px: `text-32 md:text-48 lg:text-72`.

| Утилита | Размер | Интерлиньяж | Трекинг |
|---|---|---|---|
| `text-14` | 14px | 1.5 | — |
| `text-16` | 16px | 1.6 | — |
| `text-18` | 18px | 1.6 | — |
| `text-24` | 24px | 1.3 | −0.01em |
| `text-32` | 32px | 1.18 | −0.02em |
| `text-48` | 48px | 1.06 | −0.025em |
| `text-72` | 72px | 1.0 | −0.03em |

Заголовки — вес 600. Скругления — не больше 4px (вся шкала `rounded-*` сведена к 4px).
Теней нет (шкала `shadow-*` = `none`), глубина — контрастом фонов.

Сетка: максимум 1280px, поля 24px на мобильном / 64px на десктопе.
