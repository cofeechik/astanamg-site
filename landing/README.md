# AMG — лендинг «Характер»

Новая версия по выбранной концепции №3: лайм #C0E52A, угольный цвет, крупная типографика и обновлённый логотип.

Зелёная подложка первого экрана — ровный прямоугольник. Изображение кухни не содержит окон или городского пейзажа.

## Запуск и публикация

Самостоятельный статический сайт. Сборка и npm не нужны. Откройте `index.html` или укажите эту папку как корень статического хостинга. Выложить нужно HTML, CSS, JS и `assets/` вместе.

Опубликованная версия: https://astana-mebel-studio.cofeechik.chatgpt.site (доступ определяется настройками Sites).

Корневая Next.js-реализация сохранена. Она не собирает эту папку; для публикации выбранного лендинга используйте именно `landing/`.

## Функции

- Адаптивная вёрстка, мобильное меню, категории и FAQ.
- Галерея фотографий с открытием в диалоге и закрытием Escape.
- Выбор категории заполняет форму.
- Форма открывает WhatsApp с подготовленным сообщением; пользователь отправляет его сам. Серверного хранения заявок нет.

## Изображения

`assets/kitchen-hero.png` — созданная с помощью ImageGen интерьерная визуализация для первого экрана, не реальный завершённый проект клиента. `assets/amg-logo.png` — новый растровый логотип на прозрачном фоне. Остальные используемые фотографии получены с исходного сайта astanamg.kz.

Проверены ширины 1440, 390 и 320 пикселей, загрузка изображений, якоря, меню, галерея и подготовка сообщения. Для рабочего сайта нужен действующий WhatsApp клиента по указанному номеру.
